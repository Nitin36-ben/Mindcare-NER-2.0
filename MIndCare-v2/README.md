# MindCare NER 2.0 🧠
> Clinical Cognitive Assessment Battery & Tele-Health Companion for Geriatric Dementia Care (Age 55+)

Developed for **Smart India Hackathon (SIH)**.

## Key Features
- **Geriatric Gatekeeper**: Mandatory 55+ clinical validation protocol.
- **5-Stage Cognitive Battery**: Visual CST, odd-one-out focus, Trail Making (TMT-A), category fluency, and Stroop inhibition.
- **Motor Rhythmicity & Tremor Tracking**: High-resolution touch interval variance analysis ($\sigma$).
- **Acoustic Hesitation Analyzer**: Web Audio API pause-ratio detection for speech dyspraxia.
- **Zero-Internet Node**: Offline PWA caching, local IndexedDB photo vault, and P2P QR telemetry sync.
- **Tri-Lingual Interface**: Assamese, Hindi, and English.

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3
- Storage: IndexedDB, LocalStorage, Cache API (Service Worker)
- Audio/Speech: Web Audio API, Web Speech API
- Telemetry & Reports: Chart.js, jsPDF, QRCode.js
